The five rules the file needs
1. One row per squad, position and metric. Columns A to C are the key; a repeat of the same three is a duplicate and fails.
2. The All positions row carries the calculation. Position rows leave D to G empty and inherit it, because a position changes numbers, never the way a metric is measured.
3. A gameday is a column, and the header text is the marker. Add GD-5 by adding a column. Nothing in the file caps how many.
4. Blank means different things by row type, which is the one thing to get right: blank on an All positions row is no target that day; blank on a position row means inherit the squad number. Type none in a position cell to say the day genuinely has no target.
5. imports_used takes 3, 5, 10 or All. Six metrics per squad is the ceiling, checked on import rather than in the file.
Reading the rows
Squad rows carry the metric, its calculation and the squad-wide targets. Five of these define the whole setup for a squad.
Position rows carry only the cells that differ. Three cells here replace what would be three full rows of repetition.
Empty cells are the norm, not an omission. Most squads target four or five days out of seven.
The alternative, and why not
One row per target reads better to a machine and needs no blank-means-inherit rule, but the same squad, metric and calculation repeat on every line.
