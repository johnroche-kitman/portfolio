Also checked, and not blocking
A gameday column the file introduces, say GD-5, is created rather than rejected. Calculation values typed on a position row are ignored with a note, because a position changes numbers and never the calculation. A blank sheet clears nothing — removing a target means deleting it on screen.
Worth deciding before build
Whether an import replaces a squad's targets outright or merges into what is already there. Merge is safer and matches how people will use this, but replace is what someone expects when they edit the file they just exported.
